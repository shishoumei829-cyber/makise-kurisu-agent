# Amadeus MVP 状态说明（非技术版）

## 这是什么

Amadeus 是一个**有情感连续性的本地 AI 伴侣**：

- 对话后情绪会变化，不会每轮重置
- 关系与记忆会积累
- 空闲时可能主动开口
- 角色风格有一致性保护

## 现在算不算「产品」

**算 MVP 产品原型，不算可售卖商业产品。**

Windows 安装包已可本地生成：`dist/Amadeus Setup 1.0.0.exe`（需本机 Ollama）。

你可以把它理解为：

- 已经具备完整核心体验机制
- 已经具备「打开 → 自检 → 提示缺什么」的封装
- 仍需要演示素材与（若商用）合规边界

## 用户怎么用（最简单）

1. 安装 Node.js 与 Ollama
2. 在项目目录执行 `npm install`
3. 启动：
   - 浏览器模式：`npm run dev`，打开 `http://localhost:3000`
   - 桌面模式：`npm start`
4. 若页面顶部出现黄条提示，按提示补齐（通常是 Ollama 或模型）

## 启动自检会检查什么

| 项目 | 是否必须 | 说明 |
|------|----------|------|
| Ollama | 必须 | 本地 LLM 服务 |
| 对话模型 `kurisu:latest` | 必须 | 主对话 |
| RAG 索引 | 可选 | 长期记忆检索 |
| 嵌入模型 | 可选 | RAG 需要 |
| TTS 语音 | 可选 | 不影响文字聊天 |

访问 `http://localhost:3000/health` 可查看机器可读状态。

## 与「玩具」的区别

玩具：只能开发者自己玩，外人不知道怎么启动。  
MVP：有自检、有提示、有一键启动路径、有文档与测试护栏。
