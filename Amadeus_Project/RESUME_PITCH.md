# Amadeus 项目简历包装

本文件用于把 Amadeus 按不同求职方向快速改写为简历与面试表达。

## 电梯介绍 (30 秒)

我做了一个本地运行的 AI 伴侣系统，不只是调用 LLM，而是实现了 PAD 情绪、动机目标策略、行为决策和长期记忆编排，让角色在多轮对话中保持一致性和连续性。系统基于 Node.js + Electron + Ollama + LangChain，支持可选视觉、TTS 和 RAG。

## AI 岗版本 (LLM Application Engineer)

- 在本地 LLM 上实现认知编排链路：`PAD -> 动机/目标/策略 -> 行为候选打分 -> Prompt 组装`
- 设计并落地多轮对话对齐与上下文预算策略，平衡角色一致性与 token 成本
- 构建 OOC 防护与回复修复机制，降低角色出戏与风格漂移
- 引入 BDI 异步推断用户状态，驱动关系策略与主动交互行为
- 基于 LangChain + hnswlib 搭建本地 RAG，支持知识库增量更新

## 全栈/客户端版本 (Full-Stack + Desktop)

- 使用 Express 构建对话、状态、视觉、TTS、设计任务等 API 编排层
- 基于 Electron 实现桌面常驻窗口、托盘、全局快捷键与安全预加载桥接
- 设计前后端状态可观测面板，展示 PAD、记忆和内部策略状态
- 通过本地脚本和环境变量体系支持一键启动与低显存机器运行
- 将运行数据与代码目录解耦，提升可维护性与部署清晰度

## 开源版本 (Maintainer Narrative)

- 模块化拆分 `cognitive/` 与 `lib/`，提高功能迭代可控性
- 建立可读文档体系：状态文档、GPU 调优文档、升级路线文档
- 对核心行为链路增加 guardrail 设计，减少回归风险
- 面向贡献者提供清晰的运行、调试和改动边界说明

## 面试高频问题备答

1. **你和普通聊天机器人有什么差异？**
   - 我不是只改 system prompt，而是做了可演化的状态机与策略层。
2. **怎么控制角色不出戏？**
   - 多层防护：输入对齐、OOC 检测、回复修复、流式与定稿一致性策略。
3. **为什么做本地化？**
   - 隐私、成本、可控性，且便于研究情感与记忆机制。
4. **最难点是什么？**
   - 在真实对话中平衡角色风格、信息正确性和延迟体验。
