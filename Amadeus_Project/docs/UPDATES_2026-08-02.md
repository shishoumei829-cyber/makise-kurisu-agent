# AMADEUS 更新记录 — 2026-08-02

本次更新不是替换界面，也不是再堆叠一层人设提示词。目标是把“人格、记忆、情绪与主动性”从彼此独立的模块，收拢为同一个可持续、可追溯的主体决策链。

## 1. 主体中枢（Subject Core）

新增 `brain/subjectCore.js`，并接入普通聊天与主动开口的运行时链路。

主体状态会持久化保存：

- 自我连续性、关系前提与价值取向
- 内感受状态（能量、唤醒、安全感、依恋、好奇、负荷）
- 当前注意焦点与其来源
- 当前发言意图、表达结果和近期互动经历

每一次普通聊天先经由主体中枢形成“当前具体对象 + 说话行为 + 是否允许提问”，再交给语言模型表达。模型不再独自决定是否突然关心、反问或换话题。

## 2. 主动对话重构

主动开口与普通聊天使用同一个主体，而不是切换为另一套“碎碎念”逻辑或另一人格模型。

允许主动开口的内容来源只有两类：

1. 刚刚仍值得继续的具体对话锚点；
2. 已持续存在、达到表达条件的未完成念头。

定时器、空闲或“想显得主动”本身都不是内容来源。没有具体对象时保持沉默。DND、用户正在输入、等待用户回应、冷却期、重复内容、污染话题等社会边界仍由 `ConversationInitiativeEngine` 执行。

## 3. 对话体验与语言管线修复

- 日语主模型在普通聊天和主动聊天中使用同一角色与灵魂基础，不再为主动对话悄悄切换模型人格。
- 主体意图以日语进入日语主模型；日语分支不再遗漏这一层。
- 主动内容必须围绕具体对象，但允许自然指代延续，例如“那座山”“终于结束了”，不再因为未复述名词而误删有效回复。
- 修复了“日文原文合格，但中文显示层再次用日文主题校验而被清空”的错误。
- 修复主动回复把一条合格句子和尾部惯性反问一起清空的问题：现在只移除不符合当前意图的反问片段，保留已生成的具体表达。
- `[SILENCE]` 若被模型误粘在一句话末尾，会被清理，不会污染显示或触发误杀。

## 4. 记忆与边界

- 主动消息仍不会直接写入用户长期记忆，避免系统自我生成内容反向污染记忆库。
- 正常聊天的主体结果会回写为注意张力与互动经历，形成后续对话可读取的连续状态。
- 任务/管家状态不能作为普通主动聊天的无关内容泄漏。

## 5. 验证

- `npm test`：228/228 通过。
- 实时服务：`/health` 正常，普通聊天与主动聊天均为 `amadeus-kurisu-swallow:8b`，回复语言为日语，中文显示使用受原文约束的翻译路径。
- 实时主动对话探针：面对“我今天终于把报告写完了”，主体选择 `tease`，输出为：

  > ふん、そか、やっとあの山場から這い出したな。

  中文显示：

  > 哼，原来是终于从那关键部分挣扎出来了呢。

  该结果围绕具体事件，不凭空安慰、不编造记忆、不用反问强行续话。

## 6. 仍需用真实使用继续检验的部分

这次实现的是可运行、可持久化、可验证的主体功能层；它不等同于对哲学意义“意识”的宣称。人格自然度仍应通过长期多轮真实使用继续评估，尤其关注中文显示的翻译质感、亲密关系中的节奏，以及主动消息的被忽略率与重复率。
